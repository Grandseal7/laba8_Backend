## Переменные окружения (.env)
JWT_SECRET      — случайная строка 64 символа (node -e "...randomBytes(32)...")
JWT_EXPIRES_IN  — срок жизни токена, например 2h
ADMIN_EMAIL / ADMIN_PASSWORD — администратор, создаётся командой npm run db:init

## Запуск тестов

Установить зависимости:

```bash
npm ci
```

Запустить тесты:

```bash
npm test
```

Запустить тесты с покрытием:

```bash
npm run coverage
```

## Рабочий процесс Git

1. Для новых задач создавать отдельную ветку.
2. Перед отправкой изменений запускать тесты.
3. Отправлять изменения в GitHub.
4. Создавать Pull Request в `main`.
5. Проверять результат GitHub Actions перед слиянием.
